## Project Description

This project presents an unsupervised learning analysis of a Steam games dataset containing approximately 10,000 records.

The analysis includes:

- Exploratory data analysis
- Dataset cleaning and preprocessing
- Principal Component Analysis (PCA)
- K-Means clustering
- DBSCAN clustering
- Hierarchical clustering
- Feature-space clustering
- Z-Score anomaly detection
- Isolation Forest
- Local Outlier Factor (LOF)
- Comparison between anomaly detection methods
- Robustness and sensitivity analysis
- Critical analysis and ethical considerations
- Interactive visualization dashboard
